## What I'm working on

- **Ironfront** (private repo): a multiplayer survival and exploration game in Godot (C#), with server-authoritative networking and diggable voxel terrain
- **Orbitalis++**: a space mod for Minecraft (NeoForge)

## Side projects

- **PC Assistant** (private repo): a voice-assistant-style helper for my computer, written in C# (open to anyone who is on Fedora 45 KDE)
- **neuralNet** (online, on Scratch): a neural network built from scratch in Scratch
